# MiniClip Classic - master catalogue source
#
# This file is the editorial source for data/games.json. It is read by
# tools/catalog/build-catalog.mjs, which MERGES it into the existing
# data/games.json: records that already exist keep their id/slug and every
# installation field (installed, gameFile, type, width, height, thumbnail...),
# and records that exist only in data/games.json are never removed.
#
# One game per line:
#
#   Title | categories | priority | options...
#
#   categories  space separated category ids, the first one is the main one:
#               action adventure arcade driving racing sports football pool
#               shooting fighting puzzle strategy platform multiplayer flying
#               winter skill casual word card board promotional other
#               ("other" = not categorised yet)
#   priority    nostalgiaPriority: 3 iconic classic, 2 major classic-era title,
#               1 normal catalogue entry, 0 obscure / promotional / archive entry
#   options     r        verificationStatus "needs-review" (doubtful title) - every
#                        other verification level is worked out from the
#                        historical sources in tools/catalog/sources/
#               new      shown in Latest Games
#               hs       high score challenge game (an orange link in the
#                        2008-2009 Full Games List)
#               ht=...   historicalType: standard multiplayer promotional
#                        licensed sponsored seasonal political-parody
#                        external-service (default standard)
#               type=... flash html5 iframe local-web (default flash)
#               year= dev= pub=   ONLY facts we are confident about
#               aka=A; B          alternative / historical names (aliases)
#               series= order=    series name / position, when the automatic
#                                 "Title 2", "Title 3" detection can't see it
#               rel=...           relationship with Miniclip, overrides the
#                                 automatic one: developed published hosted
#                                 licensed sponsored external-service unknown
#               note=             historicalNotes
#               desc=  how=       description / instructions (only when known)
#
# Unknown facts stay empty on purpose - accuracy beats filling every field.
# Every game here must be backed by at least one file in tools/catalog/sources/
# (the build reports any that are not). Titles come from the maintainer's
# master list (compiled from several historical Miniclip game lists: 2007,
# 2008-2009, 2010), titles visible in the 2008-2009 homepage screenshots, and
# the games found missing by the 2026 audit (tools/catalog/audit-games.mjs,
# data/audit-report.json). The screenshots also supplied the "hs" challenge flags, several
# categories (the homepage category boxes), the correct spelling of
# "Adventures in Italy" and "Overkill Apache", and the Top Ten / Hot Games /
# Latest Games line-up in data/site.json.
